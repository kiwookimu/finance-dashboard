# Market Mobile Page

모바일에서 주요 시장 지표와 시장 심리 지표를 확인하는 페이지입니다. 상단 시장 추세는 고정하고, 하단은 `시장` 탭의 지표별 28일 추이 그래프와 `보유` 탭의 내 보유 기준 카드로 나눠 보여줍니다. 신호등 점수는 그래프보다 긴 260개 거래일 안팎의 분석용 데이터를 함께 사용합니다.

## 실행

```sh
node server.js
```

그 다음 브라우저에서 `http://127.0.0.1:5173/`를 엽니다.

## 배포

Node.js 20 이상이 있는 서버에서 다음 명령으로 실행합니다.

```sh
npm start
```

Render에서는 `render.yaml`의 `startCommand`와 `/api/health` 헬스체크를 사용할 수 있습니다. GitHub Pages처럼 정적 파일만 호스팅하는 환경에서는 `/api/market-overview`, `/api/market-sentiment`가 실행되지 않으므로 시장 데이터 연동이 깨집니다.

## 구성

- `index.html`: 시장 카드 화면 구조
- `styles.css`: 모바일 우선 레이아웃과 카드 스타일
- `app.js`: 시장/심리 지연 데이터 표시
- `server.js`: 외부 데이터를 가져오는 로컬 API 서버
- `scripts/backtest_signals.mjs`: 신호등 체계 과거 데이터 백테스트
- `scripts/screen_mfi_volume.mjs`: 월간 거래량 급증 + MFI 조건 스크리닝
- `scripts/screen_kr_monthly_breakout.mjs`: 한국 KOSPI/KOSDAQ 대상 월간 상승 후보 스크리닝
- `scripts/screen_us_mfi_volume.mjs`: 미국 상장 보통주/ADR 대상 월간 거래량 급증 + MFI 조건 스크리닝
- `scripts/screen_us_monthly_breakout.mjs`: 미국 상장 보통주/ADR 대상 월간 상승 후보 스크리닝

KOSPI, S&P 500, NASDAQ, SOX 반도체지수, Nikkei 225, NASDAQ 100 선물, S&P 500 선물, USD/KRW, WTI 유가, 미국 10년물 금리는 Yahoo Finance chart endpoint를 사용합니다. 하이일드 스프레드와 NFCI는 FRED CSV를 사용합니다. DDR5 16Gb 4800/5600 Spot Price는 TrendForce 공개 DRAM spot price 표를 사용합니다. Server DDR5 Contract Price는 TrendForce Server DIMM Contract Price 공개 요약을 사용하며, 숫자 가격은 멤버십 영역이라 공개값이 있을 때만 표시됩니다. DXI Index는 DRAMeXchange 공개 Market Activity의 업데이트 시각을 사용하며, 숫자 지수와 히스토리는 로그인 영역이라 공개값이 있을 때만 표시됩니다. 공포·탐욕 지수는 GitHub CSV 미러, VIX는 Cboe 일별 CSV를 사용합니다. 모두 실시간이 아닌 무료 지연 데이터입니다.

월간 거래량/MFI 스크리너는 KRX 상장법인 목록과 Naver Finance 일별 OHLCV/시가총액 데이터를 사용합니다. 기본 비교 기준은 대상월 직전 5개월 월간 거래량 평균이고, 기본 시가총액 조건은 `1조원 이상`입니다. 네 번째 인자로 `KOSPI` 또는 `KOSPI,KOSDAQ`처럼 시장 필터를 줄 수 있고, 다섯 번째 인자에 `true`를 주면 대상월 말 종가가 직전월 말 종가보다 오른 종목만 남깁니다. 여섯 번째 인자로 최소 시가총액 원화 금액을 바꿀 수 있습니다.

한국 월간 상승 후보 스크리너는 KOSPI 종목은 KOSPI, KOSDAQ 종목은 KOSDAQ 대비 상대강도를 계산합니다. 대상월 종가가 직전 5개월 종가 고점을 돌파하고, 대상월 거래량이 직전 5개월 평균의 1.8배 이상이며, 전월 말 대비 수익률이 15% 이상이고, 자기 시장 지수 대비 초과수익률이 8% 이상이며, 14일 MFI가 70 이상인 종목을 점수화합니다. 기본 시가총액 조건은 `1조원 이상`입니다.

대시보드의 `국내 추천` 탭은 `/api/stock-recommendations`를 통해 저장된 한국 월간 상승 후보 결과를 표시합니다. 탭을 여는 것만으로는 다시 계산하지 않고, `갱신` 버튼이 보내는 `refresh=1` 요청에서만 `scripts/screen_kr_monthly_breakout.mjs`를 실행해 KRX/Naver Finance 기준으로 다시 저장합니다.

미국 월간 거래량/MFI 스크리너는 Nasdaq Trader 상장 목록과 Nasdaq 일별 OHLCV/시가총액 데이터를 사용합니다. ETF, 유닛, 워런트, 우선주, 펀드, SPAC/인수목적회사, 테스트 종목은 제외하고 보통주/ADR 중심으로 계산합니다. 기본 시가총액 조건은 `1조원 이상`이며, USD/KRW 환율로 달러 기준 최소 시총을 환산합니다.

미국 월간 상승 후보 스크리너는 샌디스크처럼 한 달 안에 거래량과 상대강도가 동시에 터지는 종목을 찾기 위한 로직입니다. 대상월 종가가 직전 5개월 종가 고점을 돌파하고, 대상월 거래량이 직전 5개월 평균의 1.8배 이상이며, 전월 말 대비 수익률이 15% 이상이고, QQQ 대비 초과수익률이 8% 이상이며, 14일 MFI가 70 이상인 종목을 점수화합니다. 결과에는 다음 1/3/6개월 수익률도 저장하지만, 이는 과거 검증용이며 스크리닝 조건에는 쓰지 않습니다. 특정 종목만 확인하려면 `SCREEN_SYMBOLS=SNDK node scripts/screen_us_monthly_breakout.mjs 2025-09`처럼 실행합니다.

`미국 추천` 탭은 `/api/us-stock-recommendations`를 통해 저장된 미국 월간 상승 후보 결과를 표시합니다. 기본 시가총액 조건은 `10조원 이상`이며, 탭을 여는 것만으로는 다시 계산하지 않습니다. 조건을 충족하는 종목이 없으면 빈 후보 상태를 그대로 보여주고, `갱신` 버튼에서만 미국 스크리너를 다시 실행합니다.

## 신호등 로직

상단 시장 추세는 공개 숫자 데이터가 있는 지표를 점수화합니다. 시장 전체 판단은 과거 검증력이 더 좋았던 주가지수, SOX, 시장 폭, 공포·탐욕, VIX, VIX 기간구조, 미국 10년물 금리, 달러/원, WTI, 하이일드 스프레드, NFCI 중심으로 계산합니다. 시장 폭은 QQQE/QQQ, RSP/SPY, SMH/QQQ 상대강도와 주요 반도체 7종목의 50일선 상회 비율을 함께 봅니다. 지정학 완화 오버레이는 Nikkei 225 급등, WTI 하락, VIX 안정, 달러/원 안정, SOX/NASDAQ 반응이 함께 나타날 때 위험선호 개선으로 가산하고, 반대로 유가·VIX·환율이 뛰면 감산합니다. 단기 이벤트 오버레이는 NASDAQ 100 선물, S&P 500 선물, Nikkei 225, WTI, VIX, USD/KRW를 함께 보고 종전·휴전 뉴스처럼 하루 안에 급격히 반영되는 재료를 `단기 급등 신호` 또는 `단기 상승 강화`로 표시합니다. 점수가 높고 위험 조건이 과열되지 않으면 녹색불(`상승`), 중립이면 노란불(`중립`), 점수가 낮고 반등 확인도 약한 완만한 하락 구간이면 빨간불(`하락`)로 표시합니다. 숫자가 비공개인 DXI와 일부 계약가격은 상태 표시는 하되 점수에는 강하게 반영하지 않습니다.

점수만으로 신호를 켜지 않고, 시장 폭, VIX 기간구조, 금리 부담, 지정학 완화, 단기 이벤트, 위기 모드, 반등 확인을 묶어 상승 확률과 장세(`추세장`, `균형장`, `금리부담`, `스트레스장`)을 추가 계산합니다. 녹색불은 장세별 확률 임계값을 통과해야 켜집니다. 하락 확률은 과거 검증에서 단독 매도 신호로는 약했기 때문에 빨간불은 기존처럼 반등 확인이 약한 완만한 약세 구간에만 제한적으로 사용합니다.

그래프 색상은 방향의 좋고 나쁨 기준으로 표시합니다. 주가지수, 반도체, 메모리 가격, 공포·탐욕 지수는 오르면 녹색/내리면 붉은색이고, USD/KRW, WTI, 미국 10년물 금리, VIX는 내리면 녹색/오르면 붉은색입니다.

## 보유 포트폴리오 신호

사용자 보유 ETF 기준 별도 신호를 표시합니다. 사진과 추가 요청으로 확인한 보유 종목은 반도체/HBM, AI 전력설비, 글로벌 AI, 자동차, 사이버보안, 우주테크, AI 광통신 네트워크, 양자컴퓨팅, 네트워크 인프라, 채권혼합 ETF로 분류했습니다. 이 포트폴리오는 반도체·성장테마 노출이 높기 때문에 SOX, NASDAQ, DDR5, 서버 DRAM, VIX, 미국 10년물 금리, USD/KRW와 지정학 완화 오버레이에 더 높은 가중치를 둡니다. 시장 전체 신호와 별개로 `상승`, `중립`, `하락`을 표시합니다.

포트폴리오 신호에는 보유 ETF의 28일 상대강도와 1/3/6/12개월 장기 상대강도, 50일/200일 이동평균 위치와 정배열, 52주 고점 근접도, Naver Finance 기준 최근 5일/20일 외국인·기관 순매수 강도, 하이일드 스프레드와 Chicago Fed NFCI 기반 시장 레짐, 반도체 사이클, 시장 폭, VIX 기간구조, VIX와 S&P 500 22거래일 실현변동성 차이로 계산한 변동성 프리미엄을 함께 반영합니다. 녹색불은 `상승`, 노란불은 `중립`, 빨간불은 `하락`으로 표시하며, 점수의 강도, 상승 확률, 장세, 확신 라벨, 권장 비중을 함께 표시합니다. 적중률을 높이기 위해 녹색불은 장세별 점수·확률 구간에서만 켜고, 빨간불은 급락 공포 구간이 아니라 점수가 약하고 반등 확인이 애매한 하락 구간에만 켭니다. 권장 비중은 `약한 빨간색` 5%, `위험 경계` 75%, `중립` 80%, 그 외 구간 100%를 기본으로 하되, `금리부담` 중립 구간, 상승확률 60% 미만 구간, 하락확률 65% 이상 구간은 확률 기반으로 75~90%까지 비중을 낮춥니다. 강한 빨간색은 과거 `nextOpen` 기준에서 급락 후 반등이 자주 나와 무조건 축소하지 않고 재진입 대기 성격으로 처리합니다.

위기 모드는 VIX 급등, 하이일드 스프레드 확대, NASDAQ/SOX의 200일선 하회가 겹치는지 별도로 감지합니다. 최근 백테스트에서는 이런 스트레스 구간도 급락 후 반등이 많았기 때문에 기본 비중을 바로 낮추지 않고, VIX 40 이상 또는 하이일드 스프레드 6.5~7% 이상이 200일선 훼손과 함께 나타나는 `tailRisk`에서만 35~50% 비중 캡을 적용합니다.

보유 종목별 신호는 각 ETF의 벤치마크 대비 28일 상대강도, 1/3/6/12개월 상대 모멘텀, 50/200일 이동평균, 외국인·기관 수급, 벤치마크와 섹터 환경을 따로 점수화해 `상승`, `중립`, `하락`으로 표시합니다.

## 백테스트

신호등 체계는 다음 명령으로 백테스트할 수 있습니다.

```sh
npm run backtest -- 2025-01-01 2026-05-22 20 0.7 10 nextOpen 12
```

세 번째 인자는 기본 선행수익률을 계산할 거래일 수이고, 네 번째 인자는 최소 포트폴리오 커버리지, 다섯 번째 인자는 노출 변경 1회당 거래비용(bp), 여섯 번째 인자는 진입 방식(`close`, `nextOpen`, `nextClose`), 일곱 번째 인자는 Deflated Sharpe 산정에 사용할 추정 테스트 수입니다. 기본 진입 방식은 `nextOpen`이며, 신호 다음 거래일 시가에 진입하고 이후 시가 기준으로 청산/리밸런싱하는 보수적 실행 기준입니다. 현재 백테스트는 5/20/60거래일 선행수익률, 다음날/다음주 신호 분류 적중률, 확률 임계값별 신호 빈도와 적중률, 장세별 평균 수익률, 각 신호의 신뢰도, 점수 기반 비중과 고정 비중 비교, 거래비용 반영 전후 성과, Sharpe/Sortino/Calmar, Probabilistic Sharpe, Deflated Sharpe, 연도별 성과, walk-forward 검증, 워크포워드 비중 튜닝, 진입 방식별 비교를 함께 저장합니다. 최근 다음주 검증처럼 60거래일 뒤 데이터가 필요 없는 경우에는 `BACKTEST_FORWARD_HORIZONS=5 node scripts/backtest_signals.mjs 2023-01-01 2026-05-22 5 0.7 10 nextOpen 12`처럼 선행수익률 horizon을 줄일 수 있습니다. 워크포워드 튜닝은 이전 연도 데이터에서 후보 비중 규칙을 고른 뒤 다음 연도에만 적용하며, 학습 표본이 500일 미만이거나 기본 규칙 대비 훈련 우위가 작으면 기본 규칙을 유지합니다. 결과는 `screen_results/backtest_signals_*.json`과 `.csv`로 저장됩니다. DDR5 spot, 서버 DRAM 계약가, DXI, 과거 외국인·기관 수급처럼 전체 과거 데이터가 공개 경로로 안정적으로 제공되지 않는 항목은 백테스트에서 제외하거나 가능한 범위만 반영합니다.
